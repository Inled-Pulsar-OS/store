Pulsar Store CLI Helper

The pulsar-store command-line utility manages Flatpak applications, GNOME Shell extensions, and Sayri AI subagent skills directly from your Linux terminal.

Installation Command

Run this single line in your terminal to install the CLI on Pulsar OS or Arch Linux:

curl -fsSL https://raw.githubusercontent.com/pulsar-os/store/main/cli/install.sh | bash
Command Reference
Command Description
pulsar-store search <query> Search packages across all ecosystems.
pulsar-store install <package-id> Download, verify checksums, and install package.
pulsar-store check Check available updates for installed packages.
pulsar-store update Upgrade all installed extensions, flatpaks, and skills.
pulsar-store audit <path> Run local automated static security check on skill/extension.
