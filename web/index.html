Pulsar Store CLI Helper

Manage, install, and update Flatpak apps, GNOME extensions, and Sayri AI skills directly from your Linux terminal.

curl -fsSL https://raw.githubusercontent.com/Inled-Pulsar-OS/store/main/cli/install.sh | bash

Command Reference

pulsar-store search <query> Search packages across all ecosystems.
pulsar-store install <package-id> Download, verify, and install package.
pulsar-store check Check updates across installed software.
pulsar-store update Upgrade all installed extensions, flatpaks, and skills.
