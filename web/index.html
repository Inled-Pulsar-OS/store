Pulsar Store CLI Helper

The pulsar-store command-line utility manages Flatpak applications, GNOME Shell extensions, and Sayri AI subagent skills directly from your terminal.

Quick 1-Line Installation (Pulsar OS / Arch Linux):
curl -fsSL https://raw.githubusercontent.com/Inled-Pulsar-OS/store/main/cli/install.sh | bash
Command Reference:
pulsar-store search <query> Search packages across all ecosystems.
pulsar-store install <package-id> Download, verify checksums, and install package.
pulsar-store check Check available updates for installed software.
pulsar-store update Upgrade all extensions, flatpaks, and skills.
pulsar-store audit <path> Run local OpenCode automated security check.
